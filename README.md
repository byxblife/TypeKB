# TypeKB Prototype v0.1

## 目的

本 Prototype 用於先驗證兩個核心假設：

1. 使用者是否能在低說明成本下自然開始打字。
2. 柔和光影、ambient 音景、字母回饋與鍵盤提示是否讓使用者感到放鬆，而不是正在接受測驗。

本版本不是正式產品，也不代表最終視覺、音樂或完整內容庫。

## 已實作範圍

- 單畫面首頁與打字練習
- 首次使用引導
- 正確、錯誤、目前字母與完成回饋
- QWERTY 下一鍵與大寫 Shift 高亮
- 最近三個有效輸入字元 Backspace
- 單字間空白需實際按下 Space，並納入進度、正確率與 WPM 字元數
- 標點自動略過
- 主要打字狀態可按 Tab 切換音樂；控制元件聚焦時保留正常 Tab 導覽
- 暫停、Esc 暫停／繼續及分頁失焦暫停
- 5 種情境與對應背景色調
- 每種情境 1 組瀏覽器即時合成暫用音景
- 6 個代表性主題
- 20 句測試內容
- 6 句具公開原典來源的名人語錄
- 基本 WPM、正確率、完成句數與陪伴日數
- localStorage 本機保存
- 設定面板、音量與減少動態效果
- 桌機完整鍵盤與手機下一字母簡化提示

## 暫用內容說明

### 音樂

五組音景均由 Web Audio API 即時合成，不使用外部音樂檔，目的僅為測試音樂氛圍與情境切換。正式版本仍需完成選曲、授權與音訊品質製作。

### 名人語錄

Prototype 內的 6 句名人語錄附有作品或文獻名稱與公開原典連結。此查證僅供 Prototype 使用；正式內容庫仍需建立完整的原文語言、翻譯版本、版本資訊與內容審核紀錄。

## 本機執行

### 提供同事直接體驗

請將以下檔案提供給同事：

- TypeKB_Prototype_v0.1_Portable.zip

同事解壓縮後，使用 Chrome 或 Safari 開啟：

- TypeKB_Prototype_v0.1_Portable.html

此版本已將 Prototype 的 CSS 與 JavaScript 內嵌於單一 HTML，不需要安裝 Node.js、不需要開啟 Terminal，也不需要啟動本機伺服器。

核心打字與音景功能可在本機使用。若裝置有網路連線，會載入指定的 Google Fonts，並可開啟名人語錄的外部原典連結；沒有網路時則使用系統備援字體。

### 開發模式

```bash
npm install
npm run dev
```

預設網址：

```text
http://127.0.0.1:5173
```

## 建議使用者測試

### 測試任務

1. 不提供額外說明，請受測者自行開始。
2. 完成至少 2 句，其中故意打錯 2 至 3 次。
3. 使用 Backspace 修正一個字母。
4. 確認每個單字之間都需要按 Space。
5. 使用 Tab 開啟或關閉音樂。
6. 切換一次情境及一次主題。
7. 暫停後再繼續。
8. 調整音量或開啟減少動態效果。

### 觀察重點

- 是否能在 10 秒內理解如何開始。
- 是否會把畫面理解為速度測驗或競賽。
- 當前字母與鍵盤高亮是否足夠清楚。
- 錯誤提示是否清楚，但不造成壓力。
- 句子長度、換行及輸入節奏是否自然。
- 背景動態是否過強或分散注意力。
- 音景是否增加沉浸感，或造成干擾。
- 桌機首屏的句子、鍵盤與統計比例是否舒適。

### 訪談問題

1. 開始前與完成兩句後，你的身體或情緒有什麼變化？
2. 哪個部分最像「練習」，哪個部分最像「陪伴」？
3. 打錯字時，你是否感到被打斷或被責備？
4. 鍵盤高亮有幫助，還是造成視覺負擔？
5. 音樂與背景光影對你是加分、無感，還是干擾？
6. 下一次你會在什麼情境下打開 TypeKB？

## 進入下一階段前需要人工確認

- 放鬆感與自然度的量化成功門檻
- 正式視覺系統與品牌字體
- 正式音樂選曲及商業授權
- 30 個主題與 100 句完整內容庫
- WPM 是否需要弱化或預設收合
- 手機版是否正式計入 WPM 與正確率
- 統計區是否保留第五欄音景資訊
